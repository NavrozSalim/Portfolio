Overview

A family of catalog scrapers that pull price, stock, and title from product pages. They share one output contract so a hub can sync listings without a new parser for every channel.

Problem

Catalog data lived on other sites in inconsistent shapes. Collecting it by hand did not scale, and each channel wanted a slightly different field set.

Approach

One repo per channel and region. Prefer a vendor API, fall back to HTML. Write structured dataset rows the same way every time so downstream sync can stay boring.

Architecture

Each actor takes a product URL (or a list). Output includes success, price, stock, title, vendor, region, and error fields. They run locally with a venv or as published actors.

Challenges

Markup changes, rate limits, and incomplete records. Pipelines needed retries, clear failures, and enough structure to keep output comparable.

Result

A repeatable path from source page to standardized listing fields across US and AU catalogs.
