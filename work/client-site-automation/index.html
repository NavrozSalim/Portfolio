Overview

Frontend delivery for client presentation, plus public apps on GitHub Pages. The catalog loads products from the Fake Store API. The weather app uses OpenWeather. The older portfolio is at navrozsalim.github.io/Portfolio.

Problem

Each brief needed a public site people could click. Homework and client work both die if the only artifact is a zip on a laptop.

Approach

Ship a clean, responsive page first. Hook a real API where it helps. Publish to GitHub Pages so the link works in a CV.

Architecture

Static HTML/CSS/JS for the catalog, weather app, todo list, and portfolio. Product data comes from REST APIs. The newer Next.js site is this repo.

Challenges

Keeping the public site simple while still showing real interaction: search, filters, live weather, and error states.

Result

Live URLs for the catalog, weather checker, and portfolio — plus the source on GitHub.
