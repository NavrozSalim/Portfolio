Overview

SaaS sync lives in WEsolucions-Work/saas-store-sync. It keeps store and channel product state consistent so selling workflows do not drift.

Problem

When a store and its channels disagree, listings go stale. Manual reconciliation does not keep up with catalog changes.

Approach

Treat sync as a first-class flow. Map fields once, then keep updates moving in a predictable direction with checks for what changed.

Architecture

Channel adapters talk to a shared catalog model. Sync jobs compare remote state with the local record and apply the delta rather than rewriting everything. Scrapers in the DataHarvest family feed the same shape.

Challenges

Partial failures, mismatched identifiers, and channels that lag. The job had to be restartable without duplicating work.

Result

Integration logic that supports catalog and listing synchronization instead of one-off spreadsheet fixes.
