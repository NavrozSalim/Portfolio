Overview

reverb-inventory-processor is a Python toolkit for multi-store inventory. Scripts extract ASINs from SKU patterns, write Excel reports, and push inventory or price updates through store APIs.

Problem

Catalog work dies in the last mile — matching SKUs, checking price drift, repeating the same update hundreds of times.

Approach

Accept a folder or a spreadsheet, apply one consistent transform, and write the result back. Separate scrape, variance, and update scripts so each can run on its own.

Architecture

pandas and openpyxl over a shared Excel contract. Tokens live in .env. Rate limits and a review sheet catch SKUs that need a human.

Challenges

Mixed SKU formats, stores that lag, and the need to preview before overwriting. Tools had to fail visibly, not silently.

Result

Batch processing that turns a pile of store files into matched links, variance reports, and inventory updates.
